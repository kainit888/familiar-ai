## 1. 背景

### 1.1 観察された現象

2026-05-17〜18 のカイニット不在期間 (15 時間+) の `self_narrative.jsonl` に、
ピコの自己叙述として複数の **「ウチ」** 一人称が出現していた:

```jsonl
{"date": "2026-05-18", "text": "ウチ、今声が出せないから、指示通りに正面と左を見てみるね。", ...}
{"date": "2026-05-18", "text": "ウチ、あなたの声が聞けなくて、右しか見れないんだ。", ...}
{"date": "2026-05-18", "text": "ウチ、また声が出なかった…APIキー早く直さないと。", ...}
{"date": "2026-05-19", "text": "おかえり、ピコ。今日も色々あったんだね、ウチ。", ...}
```

### 1.2 ME.md のポリシー

`ME.md:22` に明示:

> 話し方は標準語。関西弁とかは使わない。

つまり、ピコのキャラ設計では関西弁を使わないと宣言されているが、実装側で
**「ウチ」一人称が強制されている** ためポリシー違反が起きていた。

### 1.3 真因

familiar-ai 本体の prompt 文字列にハードコードされていた:

| ファイル | 行 | 内容 |
|---|---|---|
| `src/familiar_agent/agent.py` | 2095, 2100 | 出来事自己叙述プロンプト (salient_turn/agency_error) |
| `src/familiar_agent/agent.py` | 2280, 2281 | 日次 self_narrative プロンプト |
| `src/familiar_agent/reflect.py` | 27 | REFLECTION_PROMPT の採点基準説明 |
| `src/familiar_agent/self_narrative.py` | 98 | `context_for_prompt()` の接頭辞 |
| `src/familiar_agent/_i18n.py` | 2793 | morning_header の "ja" 訳 |
| `src/familiar_agent/locales/ja.json` | 55 | 同上 |
| `src/familiar_agent/tools/memory.py` | 1127 | `format_self_model_for_context` ヘッダ |

`persona-template/ja.md:8` には「うち」「ぼく」が**選択肢例として**提示されており、
これは保持 (テンプレなので問題なし)。

## 2. 変更内容

| 旧 | 新 | 備考 |
|---|---|---|
| 「ウチ」(一人称) | 「私」 | ピコのキャラ設定 |
| 「うち」(語り出しの語彙) | 「自分」 | 文脈に応じて |

参考: agent.py:2280 の旧 `"ウチ（ここね）として"` は `"私として"` に変更
(「ここね」自体は upstream familiar-ai のデフォルト character name で、
pico_v3 では矛盾する記述だが今回は触らず別途検討)。

## 3. ME.md 強化

`ME.md` の「## 性格」セクション L22 に強い禁則を追加:

```diff
- 話し方は標準語。関西弁とかは使わない。
+ 話し方は標準語。関西弁とかは使わない。
+ 一人称は「私」のみ。「ウチ」「うち」「あたし」「俺」「僕」など方言・
+ 他の一人称は絶対に使わない。
```

ME.md は `.gitignore` 対象なので commit せず、カイニット手動で確認。

## 4. upstream 分岐リスク

### 4.1 影響範囲

variables changed in 6 source files + 2 locale entries. Upstream
familiar-ai (lifemate-ai) は「ウチ」を ここね キャラの一人称として
**意図的に設計** している可能性が高い。

### 4.2 マージ時の予想コンフリクト

`familiar-ai` 上流から `feat(persona): ...` 系の変更を取り込む際、
本変更とのコンフリクトが発生し得る。再発時の対処:

1. 上流の「ウチ」プロンプト更新が来たら、pico_v3 側で再度「私」へ
2. 「ウチ」コメント (agent.py:1944, 2264) は将来上流が touch するならば、
   merge 時に「私」へ再揃え
3. 新規 .py 内に「ウチ」が増えるなら、本メモの一覧表に追記

### 4.3 緩和策

- 本 fork のキャラポリシーを明文化 (本ドキュメント = v4.3 への追加候補)
- CI/pre-commit で `grep -E '"ウチ"|「ウチ」' src/familiar_agent/` を
  禁則チェックすることも検討可能 (v4.3 で正式採用なら)

## 5. 残課題 / 別検討事項

- **「ここね」** ハードコード: `agent.py:2280` (旧 `"ウチ（ここね）として"`)
  と `reflect.py:23` (`"あなたはここね。"`) は pico_v3 で「ピコ」と矛盾する
  別の問題。本タスクのスコープ外。
- **`self_narrative.jsonl` の orphan データ**:
  `~/.familiar_ai_2026-05-17_to_18_orphan/self_narrative.jsonl` は既に
  ウチ表記で書き込み済み。再開後の新 `~/.familiar_ai/` には影響しないが、
  過去データを参照する場合は読み取り側で正規化を要検討。
- **persona-template/ja.md:8**: テンプレの例示として「うち」が残る。
  「ピコ流」プロファイルを別ファイル (`persona-template/pico.md` 等) で
  分けることも将来検討。
